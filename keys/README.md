# Test imza anahtarı

`debug-test.p12` yalnızca **deneme APK'ları** içindir (şifre: `android`). Gizli değildir.
Her deneme sürümü aynı anahtarla imzalandığı için yeni sürüm eskisinin üstüne kurulur, kayıtlar silinmez.

Google Play'e yüklenecek paket bu anahtarla değil, ayrı tutulan **yükleme anahtarıyla** imzalanacak.
O anahtar bu depoya konmaz.
